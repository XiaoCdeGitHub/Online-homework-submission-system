用户接口
作业上传
接口描述： 学生用户提交作业文件
请求URL： /user/uploadHomework
请求方式： POST (multipart/form-data)
请求参数：
| 参数名 | 类型 | 必选 | 描述 |
|-------|------|------|------|
| file | File | 是 | 作业文件，支持格式：zip、rar、doc、docx、md、jpg、png |
| userId | String | 是 | 用户ID |
| comments | String | 否 | 提交说明/评论 |
| weeks | Integer | 是 | 作业周数 |
| submitTime | String | 是 | 提交时间，格式：yyyy-MM-dd HH:mm:ss |
响应结果：
}
可能的错误信息：
"上传文件不能为空"
"用户ID不能为空"
"作业周数不合法"
"不支持的文件类型，请上传zip、rar、doc、docx、md、jpg或png格式的文件"
"文件上传失败: [具体原因]"
"系统异常，请稍后再试"

管理员接口
发布作业
接口描述： 管理员发布新作业
请求URL： /admin/publishHomework
请求方式： POST (multipart/form-data)
请求参数：
| 参数名 | 类型 | 必选 | 描述 |
|-------|------|------|------|
| file | File | 是 | 作业文件，支持格式：zip、rar、doc、docx、md、jpg、png |
| notice | String | 是 | 作业说明 |
| startTime | String | 是 | 开始时间，格式：yyyy-MM-dd HH:mm:ss |
| endTime | String | 是 | 截止时间，格式：yyyy-MM-dd HH:mm:ss |
| weeks | Integer | 是 | 周数 |
| direction | String | 是 | 方向（如：前端、后端、产品等） |
响应结果：
}
可能的错误信息：
"作业文件不能为空"
"作业说明不能为空"
"开始时间不能为空"
"截止时间不能为空"
"周数必须大于0"
"方向不能为空"
"不支持的文件类型，请上传zip、rar、doc、docx、md、jpg或png格式的文件"
"系统异常，作业发布失败：[具体原因]"
下载学生作业
接口描述： 管理员下载学生提交的作业文件
请求URL： /admin/downloadHomework
请求方式： GET
请求参数：
| 参数名 | 类型 | 必选 | 描述 |
|-------|------|------|------|
| userId | String | 是 | 学生用户ID |
| weeks | Integer | 是 | 作业周数 |
响应结果：
成功：直接下载文件（二进制流）
失败：返回错误信息

文件类型支持
系统支持的文件类型列表：
.zip - 压缩文件
.rar - 压缩文件
.doc - Word文档
.docx - Word文档
.md - Markdown文档
.jpg - 图片
.png - 图片
注意事项
所有文件上传请求需使用 multipart/form-data 格式
文件大小限制请参考系统配置（通常在application.yml配置文件中）
上传/下载可能受网络状况影响，建议前端实现上传进度提示和断点续传
对于大文件上传，建议分片处理
