支持的文件类型
系统支持以下文件类型的上传和下载：
| 类型 | 支持的扩展名 |
| ---- | ------------ |
| 压缩文件 | .zip, .rar |
| 文档 | .doc, .docx |
| Markdown | .md |
| 图片 | .jpg, .png |
用户接口
提交作业
接口描述：用户上传作业文件
请求URL：/user/uploadHomework
请求方式：POST
请求参数：
| 参数名 | 类型 | 是否必须 | 说明 |
| ------ | ---- | -------- | ---- |
| file | MultipartFile | 是 | 上传的作业文件 |
| userId | String | 是 | 用户ID |
| comments | String | 是 | 作业评论/备注 |
| weeks | int | 是 | 作业周数 |
| submitTime | String | 是 | 提交时间 |
请求示例：
POST /user/uploadHomework
Content-Type: multipart/form-data

file: [二进制文件数据]
userId: "12345678"
comments: "第一周Java作业"
weeks: 1
submitTime: "2023-09-01 12:00:00"
响应参数：
| 参数名 | 类型 | 说明 |
| ------ | ---- | ---- |
| code | Integer | 状态码，成功为1，失败为0 |
| msg | String | 响应消息 |
| data | Object | 响应数据，上传成功时为null |
响应示例：
{
    "code": 1,
    "msg": "上传成功",
    "data": null
}
错误码说明：
| 错误情况 | 错误消息 |
| -------- | -------- |
| 文件为空 | "上传文件不能为空" |
| 文件类型不支持 | "不支持的文件类型，请上传zip、rar、doc、docx、md、jpg或png格式的文件" |
| 用户ID为空 | "用户ID不能为空" |
| 作业周数不合法 | "作业周数不合法" |
管理员接口
管理员发布作业
接口描述：管理员上传作业文件
请求URL：/admin/publishHomework
请求方式：POST
请求参数：
| 参数名 | 类型 | 是否必须 | 说明 |
| ------ | ---- | -------- | ---- |
| file | MultipartFile | 是 | 上传的作业文件 |
| notice | String | 是 | 作业说明 |
| startTime | String | 是 | 开始时间 |
| endTime | String | 是 | 截止时间 |
| weeks | int | 是 | 周数 |
| direction | String | 是 | 方向 |
请求示例：
POST /admin/publishHomework
Content-Type: multipart/form-data

file: [二进制文件数据]
notice: "第一周Java基础作业"
startTime: "2023-09-01 00:00:00"
endTime: "2023-09-07 23:59:59"
weeks: 1
direction: "后端"
响应参数：
| 参数名 | 类型 | 说明 |
| ------ | ---- | ---- |
| code | Integer | 状态码，成功为1，失败为0 |
| msg | String | 响应消息 |
| data | Object | 响应数据，发布成功时为null |
响应示例：
}
错误码说明：
| 错误情况 | 错误消息 |
| -------- | -------- |
| 文件为空 | "作业文件不能为空" |
| 作业说明为空 | "作业说明不能为空" |
| 开始时间为空 | "开始时间不能为空" |
| 截止时间为空 | "截止时间不能为空" |
| 周数不合法 | "周数必须大于0" |
| 方向为空 | "方向不能为空" |
| 文件类型不支持 | "不支持的文件类型，请上传zip、rar、doc、docx、md、jpg或png格式的文件" |
下载学生作业
接口描述：管理员下载学生提交的作业
请求URL：/admin/downloadHomework
请求方式：GET
请求参数：
| 参数名 | 类型 | 是否必须 | 说明 |
| ------ | ---- | -------- | ---- |
| userId | String | 是 | 用户ID |
| weeks | int | 是 | 作业周数 |
请求示例：
ET /admin/downloadHomework?userId=12345678&weeks=1
响应：直接下载文件流，自动保存为原始文件名
错误码说明：
| 错误情况 | 错误消息 |
| -------- | -------- |
| 文件路径为空 | "文件路径不能为空" |
| 文件不存在 | "文件下载失败: [具体错误信息]" |
导出作业报告
接口描述：导出本周作业报告为Excel文件
请求URL：/admin/getFinalExcel
请求方式：GET
请求参数：
| 参数名 | 类型 | 是否必须 | 说明 |
| ------ | ---- | -------- | ---- |
| direction | String | 是 | 方向 |
| group | String | 是 | 分组 |
| weeks | int | 是 | 作业周数 |
请求示例：
1
响应：直接下载Excel文件，文件名格式为[方向][分组]-作业情况统计.xlsx
注意事项
文件上传大小限制请参考系统配置
上传成功后，系统会自动为文件生成唯一的文件名，以防止文件名冲突
所有上传的文件都将存储在阿里云OSS中，访问URL格式为：https://[bucketName].[endpoint]/[fileName]
文件下载时会自动以附件形式提供，促使浏览器下载而非在线打开
