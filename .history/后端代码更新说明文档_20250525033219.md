功能概述
为了解决同一周可能上传多个作业时，前端无法判断特定作业是否已提交的问题，我们对后端进行了如下优化：
在提交记录中添加了作业ID字段，建立与具体作业的直接关联
新增了通过作业ID判断作业是否已提交的接口
扩展了历史提交记录的返回数据，增加了作业ID和周数信息
修改了上传作业接口，增加了homeworkId参数
API接口说明

1. 上传作业接口（修改）
接口URL: /user/uploadHomework
请求方式: POST
Content-Type: multipart/form-data
参数说明:
| 参数名 | 类型 | 必填 | 说明 |
|-------|------|------|------|
| file | File | 是 | 上传的作业文件 |
| userId | String | 是 | 用户ID |
| comments | String | 否 | 提交备注 |
| weeks | Integer | 是 | 作业周数 |
| submitTime | String | 是 | 提交时间 |
| homeworkId | String | 是 | 作业ID (新增) |
返回示例:{
    "code": 200,
    "data": null,
    "msg": "上传成功"
}

2. 检查特定作业是否已提交（新增）
接口URL: /user/checkHomeworkSubmitted
请求方式: GET
参数说明:
| 参数名 | 类型 | 必填 | 说明 |
|-------|------|------|------|
| userId | String | 是 | 用户ID |
| homeworkId | String | 是 | 作业ID |
返回示例:
{
    "code": 200,
    "data": 1,  // 1表示已提交，0表示未提交
    "msg": "成功"
}
3. 获取历史提交记录（扩展）
接口URL: /user/historySubmit
请求方式: POST
请求参数:
{
    "userId": "用户ID"
}
返回示例 (新增了homeworkId和weeks字段):
{
    "code": 200,
    "data": [
        {
            "submitTime": "2023-07-26 12:00:00",
            "fileUrl": "https://oss.example.com/path/to/file.pdf",
            "comments": "第一次提交",
            "homeworkId": "hw123456789",  // 新增
            "weeks": 1                   // 新增
        }
    ],
    "msg": "成功"
}
